# \# Sistema Digital de Gestión de Envíos

# 

# \## Descripción

# 

# El Sistema Digital de Gestión de Envíos tiene como objetivo digitalizar el proceso de registro y administración de los envíos que actualmente se realiza mediante hojas físicas.

# 

# El sistema permitirá a los empleados registrar los envíos mediante jornadas, hojas y bloques digitales, conservando información de remitentes, destinatarios y datos del envío.

# 

# También contará con un Directorio de clientes para buscar y reutilizar información mediante autocompletado, además de permitir guardar automáticamente los cambios durante la captura.

# 

# El sistema permitirá finalizar jornadas, conservarlas como historial y generar documentos PDF para su previsualización e impresión. También se contempla la consulta de estadísticas y la gestión de empleados y clientes por parte del administrador.

# 

# \## Usuarios principales

# 

# \- \*\*Empleado:\*\* registra y administra los envíos durante su jornada de trabajo.

# \- \*\*Administrador:\*\* supervisa el sistema y administra empleados, clientes, contraseñas y estadísticas.

# 

# \## Funciones principales

# 

# \- Inicio de sesión y control de acceso.

# \- Gestión de jornadas, hojas y bloques.

# \- Registro y edición de envíos.

# \- Directorio y búsqueda de clientes.

# \- Autocompletado de información.

# \- Guardado automático de cambios.

# \- Historial de jornadas finalizadas.

# \- Generación, previsualización e impresión de documentos PDF.

# \- Consulta de estadísticas.

# \- Gestión de empleados y clientes.

#
