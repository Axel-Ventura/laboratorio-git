# Sistema Web de Gestión de Envíos Tehuacán

Sistema web para digitalizar y optimizar el registro y gestión de envíos de la empresa Tehuacán.

## Objetivo

Digitalizar el proceso de registro de envíos realizado actualmente mediante hojas físicas, manteniendo la estructura del formato utilizado por la empresa y permitiendo que varios empleados trabajen simultáneamente durante una misma jornada.

## Características principales

- Registro y gestión de envíos.
- Directorio de clientes.
- Trabajo simultáneo entre empleados.
- Funcionamiento sin conexión a Internet.
- Sincronización de información.
- Generación e impresión de hojas de envío.
- Gestión de jornadas de trabajo.
